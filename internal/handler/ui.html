Register sync remote

Pulls a full mirror of every map visible to a registered API key on another tileserve-go instance — versions and aliases included, under the same map UUIDs. This server signs its own short-lived JWTs using a key pair it generates itself: click "Generate key pair" below, register the resulting public key as an API key for a user on the remote instance (via that instance's "API keys" button on its Users tab), then paste the key ID that call returns into "Remote API key ID".
